# 화면설계서 — Drone Weather News Lab

- 작성일: 2026-10-19
- 프로젝트: 드론 운용 기상정보 뉴스
- 평가: 문제 1-1 기획·설계 20점 영역의 화면설계서
- 분석 대상: 서울 ASOS 기상 관측지점 (정확한 지점번호/자료기간은 자료 확보 후 확정)
- 문서 상태: **설계안 / 아직 실제 구현 화면 아님**

## 1. 이용 흐름(가장 중요)

```
[① 홈/대시보드] → [② 관측자료 관리] → [③ 분석·Fact Sheet]
                                              ↓
[⑥ 승인된 뉴스 공개] ← [⑤ 기사 검수·승인] ← [④ AI 기사 생성]
```

- 독자: **승인 완료** 기사만 읽는다.
- 기자/검토자: 자료 수집→분석→초안 생성→검수한다.
- 관리자: 상태·오류·자료를 점검한다. **로그인·역할별 접근 제한은 후속 고도화 계획**이며 이번에 이미 구현했다고 표시하지 않는다.

|---|---|---|---|---|---|---|
| S01 | 홈/대시보드 | 분석 지역(서울), 최근 관측 시각, 기간 선택, 메뉴 카드, 승인된 뉴스 | 화면 이동·기간 선택 | 최신 자료 존재 여부 및 요약 / 미수집 안내 | F01,F08 | 1-1 |
| S02 | 관측자료 수집·목록(CRUD) | CSV 업로드/API 수집 버튼, 관측 시각·풍속(m/s)·강수(mm) 표, 등록/상세/수정/삭제 | CSV/API, 레코드 입력·조회·수정·삭제 | MySQL 결과, 성공 메시지, 입력 오류 422·없는 ID 404·제약 오류 | F01,F02,F03 | 1-2 |

| S04 | AI 뉴스 초안 생성 | Fact Sheet 미리보기, 기사 지침, 모델 표시, '기사 생성' 버튼, 제목·본문, 검토대기 배지 | Fact Sheet 선택·생성 클릭 | 기사 초안 DB 저장 / API 오류 안내 | F05 | 1-2 |

## 4. 화면 간 연결 및 권한 계획

- 기본 메뉴: **대시보드 / 관측자료 / 데이터 분석 / AI 기사 / 검수·승인 / 승인 뉴스**.
- 향후 역할: 독자(승인 뉴스 조회), 기자(데이터 분석·초안·검수), 관리자(자료·검수 이력 관리). **로그인·실제 권한 검사는 후속 구현 대상**.
- 기사 상태: `검토대기` → (검수 실패) `보류` → 수정·재검수 → (모두 통과+사람 승인) `승인`.
- 화면의 '승인' 버튼 비활성화만으로는 부족하다. **서버 API 자체가 검수 실패 기사 승인 요청을 거절(예: HTTP 400)**해야 한다.
- 안전 문구: '이 화면은 관측자료 기반 뉴스 서비스이며 특정 위치의 실제 드론 비행 안전·법적 허가를 판정하지 않습니다.'

## 5. 오류 화면 및 검증 시나리오

| 상황 | 사용자에게 보이는 내용 | 확인할 증빙 |
|---|---|---|
| 자료 미수집 | '해당 기간 관측자료 없음' | 빈 상태 화면 |
| 필수값 누락 | 입력값 확인 및 422 오류 안내 | FastAPI `/docs` 응답 |
| 존재하지 않는 관측 ID | '자료 없음' 및 404 | API 테스트 화면 |
| 잘못된 숫자 / 제약 위반 | 400 또는 적절한 검증 오류, 저장 거절 | 오류 응답 캡처 |
| 검수 한 항목 실패 | 상태 '보류', 승인 불가능 | 보류 화면 + 서버 400 응답 |
| 모든 검수 항목 통과 | 검토자 승인 후 상태 '승인' | 승인 화면 + DB 기록 |

## 6. 평가 점수·제출 체크

- **1-1 기획·설계(20점):** 이 화면설계서는 필수 산출물 중 하나. 20점 전체를 단독으로 받는 것은 아님.
- **1-2(30점):** S02 MySQL CRUD/오류, S03 Fact Sheet, S04 AI 초안의 실제 실행 증빙 필요.
- **1-3(20점):** S05 검수 실패 승인 차단 + S06 승인 기사 노출의 실제 실행 증빙이 중요.
- **문제 2(30점):** ChatGPT 웹 기사 수집·Notion DB 두 개·지침 비교·오전 9시 예약은 별도 증빙 문서로 진행한다. 이 웹 화면의 필수 구현 범위에 혼동해 넣지 않는다.
- 현재 이 문서는 **설계안**. 실행 화면 캡처는 구현 후 별도로 첨부할 것.
